# Shiprocket Checkout Integration

This project demonstrates the integration of the **Shiprocket Checkout API** to manage e-commerce checkout flows, including token generation, order management, and frontend checkout integration.

## Features
- **Token Generation**: Generate a token for the Shiprocket Checkout API.
- **Order Management**: Fetch order details using the Order Details API.
- **Frontend Integration**: Implement a checkout button with Shiprocket's HeadlessCheckout.

## Tech Stack
- **Backend**:
  - Node.js
  - Express.js
  - Axios
  - Crypto (HMAC-SHA256)
- **Frontend**:
  - HTML
  - CSS
  - JavaScript (Shiprocket's HeadlessCheckout integration)
- **APIs**:
  - Shiprocket Checkout API
